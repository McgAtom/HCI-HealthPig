# HealthPig Native · watchOS + iOS

原生SwiftUI双端第7.1版。手表承担前台短时动作陪伴，手机承担记录、收藏、公开样本输入编辑、解释和独立公平性审核。最终应用不使用网页或WebView。

## 全系统构想与当前阶段

目标是iOS生态中的可爱综合健康伙伴：用户像养小宠物一样照顾自己，现实活动反哺宠物，宠物回应帮助用户回看状态。长期覆盖运动、站立、心脏相关记录、睡眠和可用的血氧记录，并探索自愿心情记录与温和陪伴。手表负责短任务，手机负责全景、趋势、解释与设置；角色为原创猪猪。

这些是分阶段的设计目标，不是健康收益或功能完成声明。当前版本已实现短时陪伴、系统圆环资格、收藏同步、步数／心率／睡眠记录与课程模型分析。个体睡眠推荐、血氧读取、长期成长体系及实验性心理健康体验属于后续构想；不以步行分类推断心理状态或综合健康评级。缺数、设备不支持或用户不授权不应被包装成个人健康失败。

## 反馈机制的设计契约

- 即时回应：约10秒有效片段驱动走动／休息／等待，用户能查看片段并改反馈，模型误判不扣奖励。
- 每日收藏：系统三环、目标与日期有效且全闭合，才解锁每日一次；角色按日期轮换，100表示游戏资格。
- 长期陪伴（方案）：用户选择的生活行动形成带来源的相伴日记与成长纪念，允许跳过；自行确认与传感器记录分开，心情不设奖惩。
- 睡眠安排（方案）：用户选择起床时间与预留在床时长，得到可改的候选休息时间，明确计算依据；缺记录仍可规划。它不是现有模型给出的个人时长推荐。
- 多维解释：各项记录独立显示时间与缺数，心率／血氧不直接改变宠物“病情”，主观感受仅依据本人表达。当前新卡全闭合门槛的可及性仍需评估，已有陪伴与记录查看不受此门槛控制。

本节将后续服务写成可评审规则；本次仅细化说明，没有新增运行功能。

## 运行

在macOS和Xcode中打开 `HealthPigNative.xcodeproj`。Phone选择 `HealthPigPhone`，Watch选择 `HealthPigWatch`。安装对应模拟器运行时后，在本目录执行：

```sh
python3 tools/run_simulators.py
```

脚本复用项目模拟器并检查配对，使用本地ad-hoc签名构建、安装和启动，不操作物理设备。恢复已安装应用：`python3 tools/run_simulators.py --reopen-only`。手表进入表盘或息屏后可重新打开，启动检查会识别实际首页。

最低工程设置iOS17、watchOS10；已构建验证Xcode27和对应模拟器SDK。真实动作需要加速度计；模拟器可使用明确标记的CAPTURE-24公开示例，不生成本人测量。

## 功能与边界

- 选择1段或3段陪伴，约10秒一段；步行、坐站、接近分界分别驱动走动、休息、等待。离开页面停止采样。
- 三个当日系统活动圆环全闭合才达到100游戏能量，解锁每日一次领取；目标无效、暂停、旧日期或过期读数不能解锁。模型判断不增减奖励，能量不是健康评分。
- 未获角色名字和图像隐藏，获得后揭晓、收藏与佩戴；没有模拟抽卡。
- HealthKit只读步数、睡眠、心率及圆环；未知不填零，时间与单位明确。两端各自读取健康记录。
- 公开模型示例可修改24项特征并重新分析；默认中文逐项编辑，名称、单位、序号和数值相邻，其他特征保留，可切换批量。包含格式校验、恢复示例和反馈；示例不保存为个人数据。
- 独立审核包含群体样本量、漏判、误判与候选比较；不宣称完全公平，不把睡眠离线审核用作个人预测。
- 动态字体、主按钮换行、大字体收藏减列、图表文本、状态图标与文字、减少动态效果及操作帮助。
- 收藏与最近摘要先本地原子保存，通过WatchConnectivity合并并确认业务保存回执。原始加速度不持久保存、不经同步通道传输。

`MotionFeatures.compute`提取24维输入，`MotionModel.score`读取随包冻结JSON，`MotionVerdict.decide`保持原分类任务。模型分数不是健康分或校准概率，Axivity公开数据结果不能直接作为Apple Watch准确率。

## 验证与版本记录

```sh
tools/check_core.sh
```

55项核心检查涵盖日期、圆环资格、领取幂等、持久化、合并、备份恢复、输入校验和冻结模型。UI测试保留在 `UITests/`。本地开发还检查了Watch46mm／42mm主操作、手机输入恢复、大字体及首页自动对比度；系统健康记录与真实硬件采集应分开评价。

当前原生快照于2026-10-21加入公开Git历史。既有提交保留早期手表实现；更早的本地原生阶段不冒充当时已公开提交。后续用真实日期的提交记录实现变化。

公开副本保留模型与原生资源，开发团队及应用标识改为通用值；PNG只删除元数据，压缩像素数据与本地素材相同。报告、同学反馈、个人健康数据、录屏、账号和设备资料不公开。

## 第7.1版输入与辅助操作补强（2026-10-22）

手机更多页把数据授权、模型体验和帮助提到常用区；分析与输入任务页隐藏底部标签栏。特征选择入口和长数值可换行，最大辅助字号下编辑方式纵排；逐项输入可用Return提交，批量输入保留换行。非法内容保持原值，恢复后重算会先清除旧结果；失焦回写同值不会清掉错误。

模型与采集失败状态请求辅助焦点，静态回应保留同义文字。手机实际执行6项默认流程／审核，以及真实系统最大辅助字号、真实系统减少动态效果各1项；默认输入的描述／触控／截断与对比度分别复验。组合审核的早期警示保留，额外按配色及截图检查黑／粉11.79:1、白／面板17.04:1。完整真人VoiceOver和外接硬件键盘导航不由自动化结果代替。

Watch46mm另通过主按钮边界、失败重试与语义、Debug大字体和独立对比度4项定向检查。固定版本标签为 `native-v7.1-2026-10-22`。

模型、采样处理与审核数值保持冻结；系统健康实测范围仍与模拟器UI检查分开。
